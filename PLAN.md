# UI Platform execution plan

Status: **working plan pending consolidated principal ratification**.

**P0** means the pre-release blocking remediation milestone. It establishes trustworthy source, package, and integration evidence before any public beta. A task closes only when its acceptance check runs in CI and passes; a required check that does not run counts as a failure.

The [architecture SOT](docs/ARCHITECTURE_SOT.md), [seven-item decision register](docs/architecture/DECISION_REGISTER.md), and five [C3 designs](docs/designs/) define the governing context. Owners are the roles defined in the SOT.

## P0 measurements

These inform the exit review and are recorded, not pass/fail:

- CSS and JavaScript size per documented import using raw, minified, gzip, Brotli, and parsed representations.
- Incremental consumer cost, tool version, environment, and baseline for every budget.
- Panda `staticCss: ["*"]` cost, Sass/Panda overlap, and producer build time.
- Named interaction traces for layout work and theme transitions.
- Accessibility coverage by widget, state, theme, viewport, locale, direction, NVDA, and VoiceOver.

## P0 dates

- **Decisions recorded:** 2026-10-16 for UIP-DEC-001 through UIP-DEC-007.
- **Evidence complete (P0 exit review):** 2026-11-27. Each decision is reviewed against its evidence. A failed evidence gate keeps the related API or capability outside stable exports.

## P1: contract and release governance

1. Define anchor-backed Button behavior: an `href` renders a native link without `role="button"`; `aria-haspopup` appears only when the trigger opens a menu, listbox, tree, grid, or dialog. Tests assert both.
2. Record APCA values from the producer pipeline as research evidence. WCAG 2.2 SC 1.4.3 and SC 1.4.11 remain the build-failing gate from P0 row 4.
3. Give each heading size 4xl–7xl a distinct computed font size, or remove the unused sizes. A test asserts distinct values.
4. Publish the support matrix, semantic-versioning policy, deprecation window, Component ACR, migration guide, and release record.

DTCG 2025.10 is a Community Group Final Report, not a W3C Recommendation, and is the target interchange format. The current Sass maps remain the source until a generator and migration test establish a replacement.

## P2: representative slice

Verify Button, one form control, one overlay, and one composite widget through source, packed, SSR/RSC, CSP, federation, visual, and Component ACR gates.

## P3: global beta

Run named standalone and federated pilots covering multi-brand coexistence, localization, bidirectional layout, responsive reflow, touch targets, contrast, measured budgets, migration cost, and support workflow.

## P4: stable release

Promote after governance ratification, provenance review, rollback rehearsal, and at least one real consumer migration rehearsal.
